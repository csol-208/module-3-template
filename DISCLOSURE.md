# Disclosure: use of software tools

Portions of the course materials in this repository, in particular the student workbooks (`session8.md`–`session10.md`, `overview.md`), the instructor answer keys in `notebooks/`, `download_data.sh` and `reports.csv`, were drafted with the aid of large language model coding tools: Anthropic Claude Opus 5.5 (model ID `claude-opus-5-5`) and earlier Claude models, accessed through the Claude Code command-line tool, beginning February 2026. The paragraph labels in `notebooks/key-labels.csv` were also made by Claude while drafting the answer key, and are described as such in the Session 9 answer key.

The authors directed this work and reviewed, tested, and validated the results, including running each answer key end to end against the live services. The authors take full responsibility for the materials, and any errors they contain.
